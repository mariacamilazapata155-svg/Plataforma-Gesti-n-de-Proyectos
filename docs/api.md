- Authentication
- Users

## Respuestas

Se siguen los códigos HTTP estándar.

200 OK

201 Created

204 No Content

400 Bad Request

401 Unauthorized

403 Forbidden

404 Not Found

422 Validation Error

500 Internal Server Error
