# Sistema de Permisos

## OWNER

Puede:

- Administrar proyecto
- Agregar miembros
- Cambiar roles
- Eliminar miembros
- Administrar tableros
- Administrar tareas

---

## ADMIN

Puede:

- Administrar tableros
- Administrar tareas
- Gestionar comentarios
- Gestionar archivos

---

## MEMBER

Puede:

- Crear tareas
- Modificar tareas
- Crear comentarios
- Subir archivos

---

## VIEWER

Puede únicamente:

- Consultar información
- Leer tareas
- Leer comentarios
- Leer actividad
- Leer archivos

No puede modificar información.
