# Contributor Covenant Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and collaborative environment for everyone participating in this project.

Participation should always be based on mutual respect and professionalism.

---

## Expected Behavior

Contributors are expected to:

- Be respectful.
- Be constructive during discussions.
- Accept feedback professionally.
- Help improve the project.
- Focus discussions on technical topics.
- Report problems responsibly.

---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment.
- Personal attacks.
- Offensive language.
- Discrimination.
- Publishing private information.
- Deliberately disrupting discussions.
- Spam or malicious contributions.

---

## Responsibilities of Maintainers

Project maintainers are responsible for:

- Reviewing contributions fairly.
- Enforcing this Code of Conduct.
- Maintaining a respectful environment.
- Resolving conflicts professionally.

---

## Enforcement

Instances of unacceptable behavior may result in:

- Warning
- Temporary restriction
- Permanent ban from contributing

depending on the severity of the behavior.

---

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Source Code
- Any project communication channels

---

## Contact

If you experience or witness unacceptable behavior, please contact the project maintainer.

All reports will be handled confidentially.
